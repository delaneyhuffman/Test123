# Test123

## Acme Robotics prototypes

This repository contains governed prototype artifacts created from approved Acme Robotics PRDs.

Current prototype branches / draft PRs:

1. **Command Queue Status and Conflict Prevention**
   - Demonstrates command lifecycle states, duplicate suppression, conflict detection, supervisor priority, and audit events.

2. **Role-Based Route Override Controls**
   - Demonstrates operator/supervisor/safety-officer route override authority, authorization outcomes, and audit logging.

These prototypes are demo artifacts only. They are not production routing, permission, or safety systems and should not be merged or deployed without PM, Engineering, Security, and operations review.
